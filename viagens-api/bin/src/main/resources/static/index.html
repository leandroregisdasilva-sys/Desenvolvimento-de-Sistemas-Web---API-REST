Agência de Viagens

Painel de gerenciamento de destinos — API REST

Endpoints

Listar todos os destinos

GET /destinos — retorna todos os destinos cadastrados

Buscar destino por ID

GET /destinos/{id}

Pesquisar destinos

GET /destinos?busca={termo} — busca por nome ou localização

Cadastrar novo destino

POST /destinos

Atualizar destino

PUT /destinos/{id} — substitui todos os dados do destino

Avaliar destino

PATCH /destinos/{id}/avaliacao — registra nota e recalcula a média

Excluir destino

DELETE /destinos/{id}
